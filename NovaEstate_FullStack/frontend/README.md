# NovaEstate — Futuristic Property Frontend

## Included pages
- `login.html` — futuristic login/demo authentication
- `index.html` — home/dashboard
- `properties.html` — search/filter/sort properties
- `property-details.html` — full property details
- `add-property.html` — add/publish property
- `map.html` — Leaflet/OpenStreetMap map + browser location
- `profile.html` — profile/preferences
- `logout.html` — logout screen

## Run
Extract the folder and open `login.html`, or use VS Code Live Server /:
