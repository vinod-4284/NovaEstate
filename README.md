# 🏡 NovaEstate – Real Estate Management System

NovaEstate is a full‑stack property listing and estate management application built with **Spring Boot (backend)** and **HTML/CSS/JS (frontend)**. It provides secure user authentication, property listings, and RESTful APIs with PostgreSQL integration. Designed with clean architecture, it ensures scalability, responsive UI, and a foundation for future enhancements.

---

## ✨ Features
- 🔐 User Authentication (register, login, manage accounts)
- 🏠 Property Listings with detailed information
- 📊 RESTful APIs powered by Spring Boot
- 🎨 Responsive frontend with sidebar and topbar navigation
- 🧹 Clean architecture for scalability

---

## ⚙️ Tech Stack
- **Backend:** Java, Spring Boot, REST APIs  
- **Frontend:** HTML, CSS, JavaScript  
- **Database:** PostgreSQL  
- **Version Control:** Git & GitHub
